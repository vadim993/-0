git clone — клонирует удалённый репозиторий.  
git status — показывает статус изменений.  
git add — добавляет файлы в индекс.  
git commit — фиксирует изменения с сообщением.  
git push — отправляет коммиты на сервер.  
git pull — загружает и объединяет изменения из сервера.  
git branch — показывает/создаёт/удаляет ветки.  
git checkout — переключает ветки или восстанавливает файлы.  
git merge — объединяет ветки.  
git log — показывает историю коммитов.
